== Présentation de la solution

ChartDB est un outil de visualisation et de modélisation de bases de données open source. Il permet de générer des diagrammes Entité-Association (ERD) interactifs sans nécessiter de connexion directe permanente entre l'outil et l'instance de base de données, grâce à l'exécution d'une requête d'introspection sécurisée (*Smart Query*).

== Prérequis

* Disposer d'un serveur ou poste de travail exécutant Linux Ubuntu.
* Avoir le service Docker et le plugin Docker Compose installés et fonctionnels.
* Disposer des accès administrateur (`psql`) à l'instance cible (ex. PostgreSQL ou TimescaleDB).
* La commande psql doit être installée :
+
[source,bash]
----
sudo apt install postgresql-client-common
----

== Déploiement de ChartDB avec Docker

=== Déploiement via Docker Compose (Recommandé)

1. Créer un répertoire dédié au service sur l'hôte :
+
[source,bash]
----
mkdir -p /opt/chartdb && cd /opt/chartdb
----

2. Créer le fichier `docker-compose.yml` :
+
[source,bash]
----
nano docker-compose.yml
----

3. Insérer la configuration suivante :
+
[source,yaml]
----
version: '3.8'

services:
  chartdb:
    image: ghcr.io/chartdb/chartdb:latest
    container_name: chartdb
    ports:
      - "8080:80"
    environment:
      - DISABLE_ANALYTICS=true
    restart: unless-stopped
----

4. Lancer le conteneur en arrière-plan :
+
[source,bash]
----
docker compose up -d
----

=== Déploiement alternatif via Docker Run

Exécuter la commande suivante dans un terminal :

[source,bash]
----
docker run -d \
  --name chartdb \
  -p 8080:80 \
  -e DISABLE_ANALYTICS=true \
  --restart unless-stopped \
  ghcr.io/chartdb/chartdb:latest
----

NOTE (Information ℹ️) : Le service est désormais accessible depuis un navigateur web à l'adresse `http://localhost:8080` ou `http://<IP_SERVEUR>:8080`.

== Introspection et génération du schéma

=== Récupération de la Smart Query

1. Ouvrir l'interface web de ChartDB (`http://localhost:8080`).
2. Cliquer sur **Create new diagram**.
3. Sélectionner le moteur de base de données correspondant (ex. **PostgreSQL** pour une instance PostgreSQL ou TimescaleDB).
4. Copier la requête SQL (*Smart Query*) générée automatiquement par l'interface.

=== Exécution sur le conteneur cible (PostgreSQL / TimescaleDB)

1. Se connecter au conteneur Docker hébergeant la base de données :
+
[source,bash]
----
docker exec -it <nom_conteneur_db> psql -U <utilisateur> -d <nom_de_base>
----

2. Coller et exécuter la *Smart Query* récupérée à l'étape précédente.

3. Copier l'intégralité du résultat JSON retourné par le terminal.

WARNING (Avertissement ⚠️) : S'assurer de copier l'intégralité du flux JSON sans tronquer le résultat pour éviter les erreurs de parsing lors de l'importation.

=== Importation et visualisation dans ChartDB

1. Retourner sur l'interface de ChartDB.
2. Coller le résultat JSON dans la zone prévue à cet effet.
3. Valider pour générer le schéma interactif.
4. Réorganiser visuellement les tables si nécessaire.

TIP (Astuce / Idée 💡) : Exporter le schéma au format d'image (PNG/SVG) ou sauvegarder la définition JSON pour conserver un instantané de la structure de la base dans la documentation du projet.
