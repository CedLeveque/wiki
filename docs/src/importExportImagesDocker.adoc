Pour récupérer une image Docker et la sauvegarder sous forme de fichier tar, il faut utiliser la commande docker save.

Voici comment procéder étape par étape :
1. Télécharger (pull) l'image si ce n'est pas déjà fait

Assurez-vous que l'image est présente sur votre machine locale :
Bash

docker pull nom_de_image:tag

(Par exemple : docker pull ubuntu:latest)
2. Exporter l'image au format tar

Utilisez la commande docker save avec l'option -o (pour spécifier le fichier de sortie) ou une redirection > :
Bash

docker save -o mon_image.tar nom_de_image:tag

Exemple concret :
Bash

docker save -o ubuntu_latest.tar ubuntu:latest

Astuces utiles

    Compresser directement en .tar.gz (pour réduire la taille du fichier) :
    Puisque docker save produit un fichier .tar non compressé, vous pouvez le combiner avec gzip :
    Bash

    docker save nom_de_image:tag | gzip > mon_image.tar.gz

    Restaurer (importer) l'image plus tard :
    Si vous souhaitez un jour réimporter cette archive sur une autre machine Docker, utilisez la commande docker load :
    Bash

    docker load -i mon_image.tar

    (Ou si vous l'avez compressée : gunzip -c mon_image.tar.gz | docker load)

Définition d'un yaml

==== Exemple de fichier de configuration yaml avec une timescaledb :
[source,yaml]
----
services:                                           # Section définissant les services (conteneurs) à exécuter
  timescaledb:                                      # Nom du service dans Docker Compose
    image: timescale/timescaledb:2.18.0-pg15-oss    # Image Docker utilisée (TimescaleDB v2.18.0 sur PostgreSQL 15, version Open Source)
    container_name: timescaledb                     # Nom personnalisé donné au conteneur lors de son exécution
    restart: always                                 # Redémarre automatiquement le conteneur en cas de plantage ou au redémarrage du démon Docker
    environment:                                    # Définition des variables d'environnement passées au conteneur
      - POSTGRES_USER=admin                         # Nom de l'utilisateur administrateur créé par défaut
      - POSTGRES_PASSWORD=password123               # Mot de passe associé à l'administrateur
      - POSTGRES_DB=timescaledb                     # Nom de la base de données créée automatiquement au premier lancement
    ports:                                          # Redirection des ports réseau
      - "5432:5432"                                 # Mappe le port 5432 de la machine hôte vers le port 5432 du conteneur (port standard PostgreSQL)
    networks:                                       # Réseaux Docker auxquels le service est connecté
      - iot-network                                 # Référence au réseau déclaratif "iot-network"
    volumes:                                        # Configuration du stockage persistant
      - tsdata:/var/lib/postgresql/data             # Mappe le volume nommé "tsdata" vers le dossier de données interne de PostgreSQL
    logging:                                        # Gestion de la collecte des logs du conteneur
      driver: "json-file"                           # Utilise le pilote de logs standard au format JSON
      options:                                      # Options de rotation pour éviter de saturer le disque
        max-size: "20m"                             # Taille maximale de 20 Mo par fichier de log
        max-file: "3"                               # Conservation de 3 fichiers maximum (rotation des logs)

networks:                                           # Section de déclaration des réseaux Docker
  iot-network:                                      # Clé de référence interne utilisée dans la section services
    external: true                                  # Indique que le réseau n'est pas créé par ce fichier Compose mais existe déjà
    name: yaml_iot-network                          # Nom réel du réseau préexistant créé sur l'hôte Docker

volumes:                                            # Section de déclaration des volumes de stockage
  tsdata:                                           # Déclaration du volume nommé pour la persistance des données
----
