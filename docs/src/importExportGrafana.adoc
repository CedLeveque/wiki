Pour exporter un tableau de bord (dashboard) Grafana et le réimporter sur une autre machine, la méthode la plus simple et la plus courante consiste à utiliser le format JSON. C'est rapide et cela transmet toute la configuration des graphiques.

Voici la marche à suivre étape par étape :

== Exporter le dashboard (depuis le PC d'origine)

* 1. Ouvrir le dashboard: PC d'origine. Aller sur le tableau de bord à transférer.
* 2. Accéder au menu de partage: Icône Partager. Cliquer sur l'icône Share (Partager) en haut à droite de l'écran (Trois points reliés ou à une flèche sortant d'une boîte).
* 3. Choisir l'onglet d'export: Onglet Export. Dans la fenêtre qui s'ouvre, cliquer sur l'onglet Export.
* 4. Télécharger le fichier: Sauvegarde du JSON. Cliquer sur le bouton Save to file. Cela va télécharger un fichier portant l'extension .json sur l'ordinateur (par exemple, mon-dashboard.json).Note : Si le dashboard doit être partagé avec quelqu'un qui n'a pas exactement les mêmes noms de bases de données, il est possible activer l'option "Export for sharing externally". Il ne reste plus qu'à transférer ce fichier .json sur l'autre PC (via une clé USB, un e-mail, Slack, etc.).

== Réimporter le dashboard (sur un nouveau PC)

* 1. Aller dans le menu Dashboards: Nouveau PC. Sur la nouvelle instance Grafana, cliquer sur l'icône Dashboards (le raccourci avec quatre petits carrés) dans la barre latérale gauche.
* 2. Lancer l'importation: Bouton Import. Cliquer sur le bouton New puis sélectionner Import (ou cliquer directement sur Import selon votre version de Grafana).
* 3. Charger le fichier JSON: Upload.Cliquer sur le bouton Upload dashboard JSON file et sélectionner le fichier .json précédemment transféré.
* 4.Associer les sources de données: Dernière étape. Grafana vous demandera de confirmer le nom du dashboard et, surtout, de sélectionner la source de données (Data Source) correspondante sur ce nouveau PC (par exemple, base Prometheus, InfluxDB, etc.). Une fois choisi, cliquer sur Import.

WARNING Attention au piège classique : Le dashboard importé s'attendra à trouver des données. Si les sources de données (Data Sources) sur le nouveau PC n'ont pas exactement le même nom ou ne sont pas encore configurées, les graphiques afficheront des erreurs ou resteront vides. Penser à configurer vos bases de données sur le nouveau Grafana avant ou juste après l'import !
